Get DSiForge

Download the source from GitHub, then run DSiForge locally with Python. The app keeps checks read-only and backups safe.

Download from GitHub Back to Site
Windows

Run with Python

From the DSiForge folder:

py dsiforge.py
Linux / macOS

Run with Python

From the DSiForge folder:

python3 dsiforge.py

What the download includes

Desktop GUI, Terminal UI, scanner, reports, and backup tools.

  1. Open `dsiforge.py`.
  2. Press `1` for Terminal UI or `2` for Desktop GUI.
  3. Choose your SD card root.
  4. Scan first, then create a backup before changing anything manually.

Repository

DSiForge is hosted at https://github.com/1moonbyte1/DSiForge.
